## 프로젝트 소개

이 프로젝트는 퇴근을 목표로 한 관찰 기반 1인칭 탐색 게임입니다. 

**8번 출구**를 레퍼런스로 제작된 이 게임은, 
오늘도 힘겹게 야근을 이어가던 개발자 김씨는 퇴근을 하기위해 엘리베이터에 탔지만 
오늘따라 이상한 회사 분위기와 함께 이상현상이 존재하는 사무실에 도착했다.

하지만 오늘의 회사는 어딘가 이상합니다..

엘리베이터는 각 층마다 멈춰 서며 플레이어에게 선택을 강요하고, 플레이어는 각 층에서 발생하는 이상현상 유무를 관찰하고 판단해야 해야합니다.

플레이어의 목표는 간단합니다.
각 층에서 이상현상을 정확히 판별하며 무사히 퇴근하는 것!

플레이어의 관찰력과 판단이 곧 생존이자 퇴근으로 이어집니다..

## 게임 특징

### 핵심 메커니즘
이상현상 탐색 및 유무 판단, 있다고 판단시 엘레베이터 위층 버튼, 없다고 판단시 아래층 버튼 

### 차별 요소 / 컨셉
- 기존 8번 출구와 다른 차별점 : 엘리베이터를 이용해서 진행
- 컨셉 : 오피스 배경

---

## 플레이 방법
- **이동** : WASD
- **달리기** : 왼쪽 Shift   
- **상호작용** : E, 마우스 좌클릭

각 층에서 이상현상이 발견되었다면, 엘리베이터로 돌아가 이전 층으로 이동해야 합니다.

반대로 현재 층에 이상현상이 없다고 판단된다면, 아래층으로 내려면 됩니다.
